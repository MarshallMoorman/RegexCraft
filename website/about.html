About RegexCraft

A professional desktop workbench for people who live in regular expressions.

RegexCraft started as a focused answer to a simple need: a modern, cross-platform tool that treats regex as first-class craft — testing with real engines, honest multi-flavor fidelity, GREP for whole trees, code generation you can paste into production, and room to compare and debug without leaving the desktop.

Who builds it

Created and maintained by Marshall Moorman. The project is open source on GitHub.

Stack

  • .NET 10 — application runtime and System.Text.RegularExpressions
  • Avalonia 12 — cross-platform UI (Windows, macOS, Linux)
  • AvaloniaEdit — pattern and subject editors with syntax highlighting
  • PCRE.NET — PCRE2 engine
  • Jint — embedded JavaScript engine for JS / TypeScript flavors
  • NUnit — unit and headless UI tests

License

RegexCraft is released under the MIT License. You are free to use, modify, and distribute it with attribution.

Privacy

RegexCraft is a local desktop app. Library, history, and settings are stored in your OS application-data folder. There is no account system and no cloud sync in the core product.
