How to install

  1. Download the zip for your platform from public releases.
  2. Extract the archive to a folder you control.
  3. Run RegexCraft.App (or RegexCraft.App.exe on Windows).

Builds are self-contained — they include the .NET runtime. On macOS, the first launch may require right-click → Open (or System Settings → Privacy & Security) if Gatekeeper blocks an unsigned app.
