Everything you need to craft regexes

A single desktop app for exploration, debugging, and production-ready patterns — not just a web playground.

M

Live Match & Groups

Subject highlighting for matches and capture groups, expandable equal-width match cards, and one-click copy or jump.

R

Replace & Split

Live preview with substitution highlighting and familiar backreferences — $1, ${name}, and more.

≡

Multi-flavor testing

.NET, PCRE2, JavaScript (Jint), plus High/Approximate flavors for Python, Java, PHP, Ruby, Go, Rust, and others.

C

Compare mode

Side-by-side results for 2–4 flavors: validity, matches, groups, fidelity badges, known differences, and a copyable summary.

D

Debug step-through

Educational walk-through for the .NET engine — F10/F11, pattern and subject focus, captures, and clear messaging when unavailable.

G

GREP across files

Search and replace over folders with include/exclude globs, async progress, cancellation, dry-run, and backups.

{ }

Code generation

Emit ready-to-paste snippets for C#, JavaScript, TypeScript, Python, PHP, Java, Go, Rust, Ruby, Perl, Kotlin, and Swift.

L

Library & History

Twenty built-in common patterns plus your saves, categories, tags, favorites, and searchable history — persisted locally.
