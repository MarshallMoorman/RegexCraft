# Screenshots

PNG images in this folder are generated by automated Avalonia headless tests for use in the root README and user docs.

## Regenerate

```bash
dotnet test --filter Category=Screenshots
```

Requires Avalonia.Headless with Skia (`UseHeadlessDrawing = false`). See `tests/RegexCraft.Tests/Headless/ScreenshotTests.cs`.

## Files

| File | Content |
|------|---------|
| `main-test-light.png` | Match mode, light theme |
| `main-test-dark.png` | Match mode, dark theme |
| `main-replace.png` | Replace mode |
| `main-generate.png` | Generate mode |
| `main-grep.png` | GREP mode |
| `main-library.png` | Library sidebar |
| `about-light.png` | About dialog (light) |
| `about-dark.png` | About dialog (dark) |

Do not commit temporary or low-quality captures.
